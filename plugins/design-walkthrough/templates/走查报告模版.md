## 四、验收准入规则

| 结论 | 判定条件 |
| --- | --- |
| 通过 | 无未关闭 P0/P1；P2 遗留为 0 或均已评估不影响上线；检查项完成率 100%。 |
| 有条件通过 | 无未关闭 P0/P1；存在少量 P2/P3 遗留，但均有责任人、排期、风险说明和批准记录。 |
| 不通过 | 存在未关闭 P0/P1，或核心流程/主流设备体验未达上线标准。 |
| 退回 | 设计稿、需求、测试环境、核心页面不完整，无法开展有效验收或证据不足。 |
